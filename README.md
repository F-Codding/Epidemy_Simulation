# Эпидемия — агентная симуляция SEIRD

Агентная симуляция распространения эпидемии (SEIRD) с настраиваемыми параметрами,
окном настроек, двумя режимами работы и записью результатов (CSV, GIF-анимация,
PNG-график). Всё — один Python-файл, без коробочных зависимостей от структуры
каталогов: проект можно положить в любую папку или клонировать в любое место.

**Модель.** Каждый агент — точка, движущаяся по квадратному «миру». Состояния:

| Состояние | Значение                                 | Цвет на карте |
|-----------|------------------------------------------|---------------|
| S         | здоров, восприимчив                      | синий         |
| E         | инкубационный период (заразен, не болеет)| жёлтый        |
| I         | болеет, активно заражает                 | красный       |
| R         | переболел, имеет иммунитет               | зелёный       |
| D         | погиб, остаётся на месте                 | чёрный        |

Цепочка: `S → E → I → {D | R | S}` (если иммунитет не выработался — снова восприимчив).
Мёртвые перестают двигаться и по умолчанию не заражают (есть отдельный флаг).

## Возможности

- Стартовое нативное окно настроек (tkinter): все параметры в одной форме, валидация с пояснениями.
- **Авто-режим** — анимация, привязанная к реальному времени (верно указанная скорость «дней/с» соблюдается, сколько бы кадров ни рисовала машина); кнопки прямо в окне.
- **Ручной режим** — шаги по N дней с лог-слайдером интервала (0.01…100 дней).
- Запись выхода: CSV-динамика по дням, GIF-анимация (опционально), PNG-график.
- Оптимизация под большие популяции: векторизация numpy + cKDTree (scipy) для поиска контактов.

## Запуск

Зависимости: Python 3.8+, `numpy`, `matplotlib`; опционально `pillow` (GIF) и `scipy` (ускоряет большие выборки).

```bash
pip install numpy matplotlib pillow scipy
```

Windows:     двойной клик по run.bat (или `run.bat` из консоли)
Linux/macOS: ./run.sh  (или `sh run.sh`)
Или напрямую:

```bash
python epid/epidemic_sim.py         # Windows
python3 epid/epidemic_sim.py        # Linux/macOS
```

Проект не зависит от директории запуска: выходные файлы всегда пишутся рядом
с программой (`epid/sims/…`), пути в скриптах относительные (`%~dp0`, `dirname $0`).

## Управление (окно симуляции)

**Авто-режим** — кнопки внизу + горячие клавиши:

| Действие | Кнопка | Клавиши |
|----------|--------|---------|
| Пауза / пуск | Пауза/Пуск | Space или p |
| Один шаг (покадровый просмотр) | Кадр вперёд | ← Right |
| Скорость (удвоить/поделить) | — | + / − |
| Вкл/выкл запись GIF | GIF: вкл | g |
| Сохранить GIF сейчас | Сохранить GIF | s |
| Выход | Выход | q / Esc |

Скорость задаётся в окне настроек (поле «Скорость анимации, дн/с») и меняется клавишами ±.
Пауза не накапливает пропущенное время.

**Ручной режим:** кнопка «Шаг →» (или Right/Space) продвигает симуляцию на
интервал дней, интервал меняет лог-слайдер; GIF-кнопки те же.

## Параметры (дефолты в окне настроек)

| Параметр | Дефолт | Смысл |
|----------|--------|-------|
| Численность населения | 500 | число агентов |
| Размер мира, сторона | 10 | сторона квадратного мира |
| Длительность, дней | 120 | длительность симуляции (потолка нет, минимум 1) |
| Скорость агентов, ед/день | 0.40 | средняя скорость движения агентов |
| Радиус контакта | 0.35 | радиус заражения |
| Вероятность заражения | 0.25 | вероятность заражения при контакте за день |
| Инкубация: мин/макс, дней | 2 / 5 | длительность инкубационного периода (E) |
| Болезнь: мин/макс, дней | 6 / 14 | длительность болезни (I) |
| Шанс иммунитета (0..1) | 0.95 | шанс иммунитета после выздоровления |
| Смертельность (0..0.999) | 0.02 | шанс смерти после болезни |
| Нулевых пациентов | 5 | число изначально больных |
| Внутр. шагов в одном дне | 8 | шагов симуляции на один день (точность) |
| Seed (пусто = случайный) | 42 | зерно генератора случайности |
| Скорость анимации, дн/с | 2.5 | скорость хода в авто-режиме (моя ±) |
| Дней за ручной шаг | 1.0 | интервал шага в ручном режиме |
| Записывать GIF | вкл | анимация (нужен pillow) |
| Кадр GIF каждые N кадров | 8 | частота снимков |
| Масштаб GIF-кадра | 0.5 | размер кадров GIF |
| Заражение от мёртвых | выкл | могут ли погибшие заражать |

## Выходные файлы

Каждому запуску — своя папка, ничего не перезаписывается между прогонами:

```
epid/sims/
└── sim-20261105_204500/        ← дата и время старта запуска
    ├── epidemic.csv            ← день,S,E,I,R,D — числа по состояниям на каждый день
    ├── epidemic.gif            ← анимация (если запись включена)
    └── epidemic_plot.png       ← график динамики отдельной фигурой
```

В конце в консоль печатается сводка: число дней, счётчики по каждому состоянию,
процент «не заразившихся» и пути файлов.

## Структура проекта


> разработки/регрессии: если вы просто хотите поиграться с симуляцией, папку `tests/`

## Тесты (только для разработки)

Тесты не открывают окон (backend Agg, Tk-диалог в headless-режиме):

```bash
test.bat      # Windows
sh test.sh    # Linux/macOS
```

Что проверяют:

- `test_start_window.py` — валидация полей окна настроек, перекрёстные проверки, потолок дней снят, seed `'' → None`, флаг заражения от мёртвых (вкл/выкл), большой days.
- `test_smoke_panels.py` — старт ровно с дня 0 (первый кадр не двигает симуляцию), скорость по реальному времени (50 дн/с → ~10 дней за 0.2 с), пауза без накопления долга, ручной шаг.
- `test_output_files.py` — finalize создаёт папку `sims/sim-…` с CSV (6 колонок, включая D) и PNG-графиком.

## Как это устроено (ключевые решения)

- **Векторизация numpy**: позиции `(n, 2)`, состояния `(n,) int8`, таймеры `(n,)`,
  скорости `(n, 2)` — движение, заражение и смены состояний выполняются массовыми
  операциями, циклов по агентам на чистом Python нет.
- **Две стратегии поиска контактов**: broadcasting-матрица `здоровые × больные`
  (точная) при малых нагрузках и `cKDTree` (ближайший больной в радиусе) при
  `sick × healthy > 1 000 000` пар; результаты эквивалентны.
- **Нормировка вероятности по шагу**: `p_step = 1 − (1 − infect_p)^dt`, поэтому
  темп эпидемии не зависит от дробности шага (steps_per_day).
- **Ход по реальному времени** (авто-режим): каждый кадр анимации продвигает
  симуляцию на `dps × steps_per_day × dt` внутренних шагов (аккумулятор,
  clamp dt до 0.5 с, батч до 8192 шагов); первый кадр только синхронизирует часы,
  чтобы не было прыжка на старте. Перерисовка не ограничивает скорость симуляции.
- **Порядок исходов болезни**: сначала бросок летальности, выжившим — бросок
  иммунитета; без иммунитета агент снова S (может болеть повторно).
- **GIF каждый N-й кадр** (`gif_every`) — запись не тормозит анимацию
  и не раздувает файл.
- **Окно настроек на нативном tkinter**: нативные виджеты не вызывают
  перерисовку matplotlib — ввод мгновенный, CPU на простое ~0%.
